# VFJ-Bench

VFJ-Bench: Evaluating captions with VLMs as judges.

This repository contains tools to generate and evaluate image captions using Vision-Language Models (VLMs).

## Files
- `vlm_as_a_judge.py`: Script to use a VLM to judge which caption is better.
- `generate_origin_captions.py`: Generates captions for original images.
- `prompts.py`: Defines system prompts for the VLM judge.
- `generate_edited_images_v2.py`: Tools for processing edited images.
